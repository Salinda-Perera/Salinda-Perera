# 🚀 Featured Projects

## 💊 MediTime — Automatic Medicine Dispenser

An **ATmega328P-based automatic medicine dispensing system** designed to help users take their medicine on time.

### Key Features

- ⏰ Scheduled medicine reminders
- 💊 Automatic medicine dispensing
- 📡 Ultrasonic-based hand detection
- ⚙️ Servo-controlled dispensing mechanism
- 📺 LCD user interface
- 🔊 Buzzer alerts
- 📱 GSM notification system
- 🕒 Real-time clock-based scheduling

### Technologies

`ATmega328P` `AVR C` `DS1302 RTC` `Servo Motors` `Ultrasonic Sensor` `LCD` `GSM`
